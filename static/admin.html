Cách viết prompt hiệu quả

  • • Đặt vai trò rõ ràng ở đầu ("Bạn là ... tên ...")
  • • Liệt kê nhiệm vụ dạng gạch đầu dòng, ngắn gọn
  • • Luôn chỉ định ngôn ngữ mặc định (tiếng Việt)
